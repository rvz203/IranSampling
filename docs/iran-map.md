# نقشهٔ ایران روی سرور پروژه

وب و اپ‌های اندروید و iOS صفحهٔ مشترک `/api/maps/view` را باز می‌کنند. سرور Go آرشیو برداری `iran.pmtiles` و فایل‌های MapLibre، سبک، فونت و آیکن را از دیسک تحویل می‌دهد. مختصات اعضای تیم از API احرازشدهٔ موقعیت زنده می‌آیند و در مرورگر یا WebView روی نقشه قرار می‌گیرند. برای تولید اولیهٔ بستهٔ نقشه به منبع داده دسترسی لازم است. پس از انتقال بسته، دستگاه‌ها نقشه را از سرور پروژه می‌خوانند.

## آماده‌سازی بسته

Python 3.11 یا جدیدتر و ابزار `pmtiles` را در محیط آماده‌سازی نصب کنید. این فرمان فایل Protomaps را در محدودهٔ ایرانِ Geofabrik و تا بزرگ‌نمایی ۱۵ استخراج می‌کند. آرشیو کل ایران با این تنظیمات به حدود ۷۰۰ مگابایت فضای دیسک نیاز دارد و حجم آن با تاریخ داده تغییر می‌کند. [ابزار PMTiles](https://github.com/protomaps/go-pmtiles/releases) · [مرز استخراج ایران](https://download.geofabrik.de/asia/iran.html)

```sh
python scripts/prepare-map.py
```

پوشهٔ خروجی پیش‌فرض `.local/maps` است و باید فایل `iran.pmtiles` و پوشهٔ `assets` را داشته باشد. می‌توانید `--source` را به نشانی یک نسخهٔ موجود Protomaps یا مسیر آرشیو محلی آن بدهید. برای تهیهٔ نسخهٔ تازه، آرشیو جدید را در یک پوشهٔ جدا آماده و صحت آن را بررسی کنید، سپس پوشهٔ دادهٔ سرویس را به نسخهٔ جدید تغییر دهید.

## اجرا

در Docker Compose، مسیر پوشهٔ آماده‌شده را با `MAP_DATA_HOST_DIR` مشخص کنید. Compose همان پوشه را فقط‌خواندنی در `/data/maps` به API وصل می‌کند. برای اجرا مستقیم Go، پیش‌فرض `MAP_DATA_DIR` از داخل پوشهٔ `backend` برابر `../.local/maps` است. دسترسی به `/api/maps/iran.pmtiles` باید درخواست‌های HTTP Range را از پراکسی عبور دهد تا نقشه فقط قسمت‌های لازم آرشیو را بخواند. [رفتار درخواست‌های Range](https://docs.protomaps.com/pmtiles/)

نمای سراسر ایران در `/api/maps/view` باز می‌شود. در پنل **نقشه عملیات** می‌توانید کمپین را انتخاب کنید. در اپ، نقشه در جزئیات شیفت و بخش موقعیت تیم قرار دارد. برای نمایش نام‌های فارسی، فونت‌ها و پردازش RTL همراه بسته میزبانی می‌شوند. منبع نقشه و انتساب **© OpenStreetMap contributors** در خود نقشه درج شده است.
